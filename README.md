# MAHI — Portfolio

A visual, motion-first developer portfolio for **Mahendra Sai Kondaveeti (Mahi)**.

## What this build includes

- Immersive animated hero with procedural canvas particles
- Floating orbital skill system
- Scroll reveal motion and magnetic buttons
- Project spotlight carousel
- Project cards for Averis, TripPilot, CYRUS, VoxGen AI and more
- Live public GitHub activity panel
- Responsive layouts for desktop/tablet/mobile
- Reduced-motion accessibility handling
- Pure static HTML/CSS/JS — deployable to GitHub Pages without a build step

## Design direction

The visual system intentionally combines editorial typography, dark glass panels, neon signal accents, orbital/particle motion, live repository data and product-style project storytelling. The implementation is original and does not copy the referenced portfolios' source code.
